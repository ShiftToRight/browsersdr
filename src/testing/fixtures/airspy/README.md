# Airspy conversion oracle

`conversion-oracle.json` contains deterministic ADC input provenance and the planar I/Q output from an independently compiled official MIT-licensed libairspy converter at revision `871fcdc6e841cae6e6b2a58fcd6596b7f7722ad2`. This is generated test data, not a received RF recording. The corresponding source is [upstream](https://github.com/airspy/airspyone_host/tree/871fcdc6e841cae6e6b2a58fcd6596b7f7722ad2/libairspy/src).

For real sample n=0…511, input unsigned ADC code is `(n*73+n*n*19)%4096`; reference float is `(code-2048)/2048`. Construct the reference with `iqconverter_float_create(HB_KERNEL_FLOAT,47)`, then call `iqconverter_float_process` for 512 real samples. Even output indices form I, odd indices form Q. The numeric JSON fields retain `printf("%.9g", value)` output. BrowserSDR compares its streaming conversion (including arbitrary USB splits and both packing modes) to this reference at six decimal places. Additional tests verify reset, decimation counts, rate conversion, filter response and recording provenance.

`FILTER-LICENSE.txt` retains the MIT notice for the standard coefficients and conversion reference (Copyright 2014 Youssef Touil). `HOST-LICENSE.txt` retains the BSD-3-Clause notice for the gain schedules from current official host revision `fc61ab6be57ed61f0e2bdd9c6dfae74cacef57d0`. Both notices are also in the shipped `THIRD_PARTY_NOTICES.md`. No later converter with the restricted Airspy ecosystem licence is included. The Sharp filter and channel Blackman kernels are generated by BrowserSDR from standard windowed-sinc formulas.

The command/ADC fixture is independently specified in `src/testing/airspyUsbFixture.ts`; it imports no client driver or converter. These checks do not prove electrical bias-tee behavior, physical Mini support, continuity or audible/off-air decoding.
