# Vice Afterglow artwork

Current production decorations follow the original BrowserSDR Vice mockup:

- `vice-mockup-sprite.webp`: lossless encoding of the original generated concept. CSS samples only the original source-panel poster (x18,y492,w251,h252) and wordmark with its palm background (x20,y10,w250,h54). This preserves the actual handwritten lettering, palm silhouettes, skyline and bold italic BrowserSDR lettering rather than generating approximate replacements. The original concept is an illustrative design; its RF values, buttons and receiver status are not rendered from this sprite. All real interface controls and plot data remain live application elements.
- `vice-header-mural.webp`: background-only header strip, created with built-in imagegen by removing the mockup's text/controls and restoring the obscured sky/foliage. CSS fits the opaque strip across the full header and scales its height to keep transparent padding outside the bar. The background continues behind the real buttons.
- `vice-fronds.webp`: separate restrained pink/violet/cyan channel-panel fronds.

The poster fills its panel's inner bottom edge and corners, with only the empty upper sky blended into the panel. It has no island outline or transparent ground margin. The real h1 retains BrowserSDR's accessible name; forced colors suppress artwork and restore ordinary readable heading text. Amber Field Deck and Midnight Observatory retain the established logo and typography.

Only the three actively rendered artwork files above are distributed. Superseded header/palm variants remain in private design records. No external game assets, product photography or additional font downloads are included. Original PNGs/prompts and dated review evidence remain in the project's private design records. All image preparation is encoding only; exact source regions are selected in CSS without altering the source bitmap.
